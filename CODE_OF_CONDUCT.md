# Community code of conduct

PTT Talk is built for trustworthy communication. The project community should
reflect that purpose: technically rigorous, respectful, privacy-conscious, and
welcoming to people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique ideas and code without attacking people.
- Assume good intent while still asking for evidence and clear reasoning.
- Respect privacy. Never publish private communications, personal data,
  credentials, device identifiers, keys, or unpatched vulnerability details.
- Make room for newcomers and explain project-specific terminology when it
  helps collaboration.
- Disclose relevant conflicts of interest and distinguish verified behavior
  from assumptions.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate
intimidation, sustained disruption, impersonation, or publishing another
person's private information without permission are not acceptable. Neither is
using project channels to coordinate abuse, unauthorized access, surveillance,
or harm.

## Scope and enforcement

This policy applies in the repository, Discussions, Issues, code review, project
events, and other spaces where someone represents PTT Talk. Maintainers may
edit or remove content, close discussions, reject contributions, temporarily
restrict participation, or permanently ban participants when needed to protect
the community.

Report conduct concerns privately to the repository maintainers. If a report
also concerns a software vulnerability, use GitHub's private vulnerability
reporting flow described in [`SECURITY.md`](SECURITY.md). Maintainers will limit
disclosure to the people needed to review and respond, while recognizing that
complete confidentiality cannot be guaranteed.
